# Salaam 和平島｜中文 Islam 學習島嶼

以 Islam Taiwan 刊載、趙錫麟教長著《穆民基礎》為依據的獨立互動導讀。六個區域、18 個短課，每課包含摘要、理解測驗及原章連結。

## 啟用 GitHub Pages

1. 前往倉庫 Settings → Pages。
2. Source 選擇 **Deploy from a branch**。
3. Branch 選擇 **main**，資料夾選擇 **/(root)**，按 **Save**。
4. 等待 Pages 建置完成；以設定頁顯示的網站連結為準。

預期網址： https://101academyforyou.github.io/islam-learning-island/

此為預期網址，需完成以上設定才會上線。GitHub Pages 網站會公開。

## 內容

- 初見港灣：名詞、真主與人類、責任。
- 信仰之庭：清真言、六信、五功。
- 功修廣場：齋戒、天課、朝覲。
- 善意市集：寬容、常用語彙、品德。
- 生活書屋：誦經、飲食、清真寺。
- 家庭花園：婚姻、幼兒禮俗、殯葬關懷。

## 本機使用

直接以瀏覽器開啟 index.html，或以任意靜態網站伺服器預覽。無建置工具、外部字型、套件、API 金鑰或後端需求。進度存於瀏覽器 localStorage，不跨裝置同步。頁面重設只影響目前網站來源的本版進度。
